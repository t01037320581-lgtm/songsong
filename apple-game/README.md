# 사과 팡

10을 만드는 사과 드래그 퍼즐 게임입니다.

## GitHub Pages 배포

1. 이 폴더를 GitHub 저장소의 루트에 업로드합니다.
2. 저장소 기본 브랜치를 `main`으로 설정합니다.
3. GitHub 저장소의 **Settings > Pages > Build and deployment**에서 Source를 **GitHub Actions**로 선택합니다.
4. GitHub에 `main` 브랜치를 push합니다.

`.github/workflows/pages.yml`이 사이트를 자동 배포합니다.
